# ENCS3320 – Socket Programming Project

## Project Overview

This repository contains a Computer Networks project focused on the practical implementation of fundamental networking concepts using **low-level socket programming**.

The project explores network communication, IP addressing, DNS resolution, routing, TCP and UDP protocols, and HTTP web server operation through practical experiments and implementations.

## Project Tasks

### 1. Networking Tools

The project includes practical experiments using common Windows CMD networking tools, including:

* `ipconfig`
* `ping`
* `arp`
* `tracert`
* `nslookup`
* `netstat`

These experiments were used to explore IP configuration, connectivity, DNS resolution, routing paths, and active network connections.

### 2. TCP Client/Server

A TCP client/server application was implemented to demonstrate reliable communication using the TCP protocol.

The implementation demonstrates concepts such as:

* Client/server communication
* Connection establishment
* Data transmission
* Acknowledgment
* Reliable data delivery

### 3. UDP Client/Server

A UDP client/server application was implemented to explore connectionless communication and compare it with TCP.

The implementation demonstrates:

* UDP communication
* Data transmission without connection establishment
* Packet ordering and delivery considerations
* Comparison between TCP and UDP

### 4. HTTP File-Sharing Web Server

A simple HTTP web server was developed to handle HTTP requests and provide file-sharing functionality.

The web server supports:

* HTTP requests and responses
* File downloading
* HTML pages
* Multilingual web pages
* `200 OK` responses
* `400 Bad Request` responses
* `404 Not Found` responses
